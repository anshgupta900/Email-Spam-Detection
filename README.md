# 📧 Email Spam Detection

A machine learning based web application that classifies emails as Spam or Not Spam.

## 🚀 Project Overview

This project uses machine learning techniques to detect whether an email is spam or not spam.

The application is developed using Python, Scikit-learn, Pandas, NumPy and Streamlit.

## 🧠 Machine Learning Models

The project uses:

- Logistic Regression
- Decision Tree
- Random Forest

## 🔧 Data Processing

The project includes:

- Data cleaning
- Missing value handling
- Invalid value handling
- Outlier detection using IQR
- Sender domain extraction
- One-hot encoding
- Feature scaling
- Train-test split

## 📊 Features

The application takes the following inputs:

- Sender Email
- Subject
- Email Length
- Number of Links
- Number of Special Characters
- Capital Words
- Attachment status

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit
